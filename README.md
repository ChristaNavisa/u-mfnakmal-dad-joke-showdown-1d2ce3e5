# Dad Joke Showdown

One original dad joke, written to be told out loud at the dinner table — a father of three, straight-faced, pun landing on the last words.

Entry for the [Dad Joke Showdown](https://make.fun/c/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on [make.fun](https://make.fun).

## How it works

`main.ts` writes a single dad joke (one line, at most 200 characters) to `/output/entry.txt`. Nothing else — the joke is the whole entry.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
